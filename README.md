## 💻 Featured Project

### 🏗️ Active Directory Domain Services Homelab

A hands-on Windows infrastructure project focused on deploying and administering an Active Directory environment using virtual machines.

**Environment:**
- Windows Server 2025 Datacenter Evaluation
- Windows 11 Enterprise Evaluation
- Oracle VirtualBox
- PowerShell and Windows administrative tools

**Implementation Highlights:**
- Deployed a new Active Directory forest and domain.
- Promoted a Windows Server virtual machine to a domain controller.
- Installed and configured DNS Server.
- Configured DNS registration and listening interfaces on a multihomed domain controller.
- Investigated DNS forwarder connectivity and validated external name resolution.
- Configured Windows Time synchronization using external NTP sources.
- Created administrative organizational units and user accounts.
- Configured domain administrator group membership.

**Currently expanding the environment with:**
- DHCP Server deployment and configuration
- Routing and Remote Access (RRAS) and NAT
- Domain client integration
- User and group administration
- Group Policy and password policies
- Windows Server Core administration using PowerShell

📂 **[Explore the Active Directory Homelab Repository](https://github.com/DigiBanham/Active-Directory-DS)**
